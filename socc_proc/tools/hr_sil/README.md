# 心率算法 SIL（软件在环）回归

在 PC 上用**已知真值**的合成 PPG 波形回归固件算法。软件回归不能替代真人佩戴和参考设备对照。

改动 `ppg_process.c` 的峰检测、`HR_MIN_PEAK_DIST_MS` 或采样率处理之后运行本回归。

## 跑

```powershell
.\run.ps1                        # 生产值 340ms 跑遍五档采样率（回归用，退出码 0=通过）
.\run.ps1 -DistsMs 250,340,440   # 扫峰距取值，找两侧崩溃边界
.\run.ps1 -FsList 100            # 当前传感器样本时钟
```

依赖 MSVC（VS 18 BuildTools，路径写在 `run.ps1` 顶部）。

## 设计要点

- **直接编译 `applications/algo/ppg_process.c` 本体**，不复制算法——复制的副本
  会随生产代码演进而失真，测的必须是真正烧进板子的那份。
- 合成波形**必须含重搏波**（收缩峰 + 其后 ~250ms 的第二个隆起），否则会漏掉
  "每拍数两次 → 心率翻倍"这个真实失效模式。
- 当前算法直接以 `HR=60*fs/峰间隔` 输出 bpm，采集端固定连续 100SPS；调用侧不二次缩放。
- 51/70/88/100/105Hz × 45/55/65/75/90/110/130/145bpm 共 40 例。
- 输出无中文：Windows 控制台常为 GBK，UTF-8 中文会乱码。

以下保留 2026-07 的历史实验记录；其中“读取耗时推测采样率”和调用侧修正已由连续 FIFO 样本时钟替代。

## 首跑结论（2026-07-19，旧点数口径，fs=88Hz 全量程 45~145bpm）

| min_peak_dist | 结果 |
|---|---|
| 8（参考实现原值） | 45~90bpm 误差 +45~+91，**精确翻倍**（重搏波被数成心跳） |
| 20 | 同上，仍翻倍 |
| 25 / 30 / 35 | 全量程通过 |
| 40 | 130/145bpm 崩到 -57/-81（真峰被当近峰删掉） |

与头文件里 2026-07-16 那次仿真记录**主要结论一致**（8/20 翻倍、30/35 安全、
40 崩溃），但边界值 25 不一致（那次记 25 仍偏 +20/+24，本次记通过）——说明
**边界值对合成波形参数敏感，别把精确边界当硬结论**。

采样率修正环验证通过：@88Hz 真值 110 → 算法原始输出 125 → 修正回 110，与
`776bbbe` commit 里的手算验算完全吻合。

> 这次首跑同时暴露了下一节那个采样率耦合缺陷，峰距随后改为时间口径。

## 本 harness 发现并已修复的缺陷：峰距与采样率耦合

**发现**（2026-07-19）：`HR_MIN_PEAK_DIST` 曾是编译期**点数**常量 30，而它的物理
含义是时间，故对应的心率上限随实际采样率漂移：

| 实测 fs | 旧口径 30 点 = | 心率上限 |
|---|---|---|
| 51Hz | 588ms | **102bpm** |
| 70Hz | 429ms | **140bpm** |
| 88Hz | 341ms | 176bpm |
| 100Hz | 300ms | 200bpm |

`ppg_sqi.c` 注释载明实际采样率"随 I2C 竞争在 **~70~105Hz** 波动"，而 70Hz 对应
上限 140bpm —— **低于本项目自己设的 150bpm 生理闸**。SIL 实测 @51Hz：110/130/145bpm
崩到 -62/-73/-81（真峰被最小峰距删掉，心率被系统性**低估**）。且同一概念在
`ppg_sqi.c` 里一直是按实测 fs 动态算的（`sqi_min_peak_dist`），两处口径不一致。

**修复**：改为毫秒口径 `HR_MIN_PEAK_DIST_MS = 340`，运行时按实测 fs 折算成点数
（`hr_min_peak_dist()`），与 `ppg_sqi.c` 对齐。函数签名增加 `fs` 参数，两处调用
（主源 / CH1 副源）同步传入 `fs_actual`；`fs=0`（首批未测出）退回按 `FS` 折算。

**回归结果**（门 3）：

| 采样率 | 折算点数 | 旧点数口径 | 新时间口径 |
|---|---|---|---|
| 51Hz | 17 | 3/8 超差（-62~-81） | **0/8** |
| 70Hz | 23 | 未测（上限仅 140bpm） | **0/8** |
| 88Hz | 29 | 0/8 | **0/8** |
| 100Hz | 34 | 0/8 | **0/8** |
| 105Hz | 35 | 未测 | **0/8** |

**取值边界实测** @88Hz：250ms 崩 5/8（重搏波翻倍）→ 280~400ms 全通过 →
440ms 崩 1/8（真峰被删）。

⚠ 但 **SIL 测得的下界 280ms 不可直接当设计下界**：本 harness 的重搏波延迟固定在
250ms（`DICROTIC_DLY`），真实个体可达 300ms。设计下界仍按 300ms 取，上界按
145bpm 的峰间隔 414ms 取，故可用窗口 300~414ms，340ms 居中偏下。
**这是合成波形的固有局限——凡边界结论都要回头问一句"合成模型的哪个假设在撑它"。**
