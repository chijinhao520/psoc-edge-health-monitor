# 引导式体检与本次报告

2026-10-29：已实现并完成离线验证，尚未烧录或实板验收。

## 使用流程

1. 在监测页点击“开始体检”。开始新体检会清除上一次保留的结果。
2. 完成手指检测：采集心率和血氧，界面提示接触、信号稳定、设备连接与超时状态。
3. 自动进入心电检测：按设备说明连接电极，积累本次心律及 HRV 数据。失败可重试，也可跳过。
4. 点击“查看报告”，查看各组已完成、已跳过或未完成状态。取消后保留已经完成的项目。
5. 流程结束后可以“重测手指”或“重测心电”；仅替换所选组，保留另一组结果。

每阶段的界面等待期限为 100 秒；手指检测同时遵守采集端原有的 90 秒测量超时。失败后等待用户重试、跳过或取消，不自动无限重测。

## 报告规则

- 本次报告保存检测完成时的数值，不跟随后台实时数据变化。
- 手指检测必须来自新的测量轮次；心电检测须确认新的分析窗口，避免上一轮结果混入。
- 两组均完成且流程结束时才显示规则评分；缺项显示“项目不全”，不能解释为正常。
- 心律来源区分模型与规则分析。呼吸率仅在有效时作为估计值保留。
- 本次快照只保存在内存，重启或开始新体检后清除，尚无长期历史存储。
- 环境、红外温度及 GSR 在监测页实时查看，未并入本次体检快照。
- 引导体检报告隐藏原有实时云端建议入口，避免实时建议与冻结报告对应不上。

## 实现位置

- `checkup_flow.h`：纯状态机、阶段超时、轮次隔离与结果快照。
- `ui_data.c` / `ui_checkup.h`：500 毫秒调度、采集命令及冻结快照评分。
- `checkup_widgets.h`：操作按钮、接触提示、项目状态与报告摘要。
- `ui_tab_monitor.c` / `ui_tab_report.c`：监测页入口和报告展示。
- `../arrhythmia_task.c`：异步申请新的心电分析窗口，清除旧窗口并确认会话编号。
