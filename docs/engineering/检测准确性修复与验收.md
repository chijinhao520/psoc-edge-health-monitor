## 1. 本次修复针对什么问题

此前的检测不准确来自多处链路问题，不能只靠调整显示值解决。

| 环节 | 发现的问题 | 当前处理 |
|---|---|---|
| PPG 采集 | FIFO 平均、读取耗时和算法采样率口径不一致；缺少可靠丢样处理 | 配置连续 100SPS、无平均、18位；批量读取，每次最多8点；空FIFO不补点，溢出/高水位/间断丢整窗 |
| 心率 | 算法与调用端重复缩放；峰距取整和边界处理存在问题 | 算法按连续样本时钟直接输出 bpm，删除二次缩放；修复平顶峰越界、工作区残留及取整 |
| 血氧 | R值尺度、乘法溢出、中位数及查表处理错误 | 用64位中间乘积，统一 R×100；修复AC峰索引、中位数及表尾；保留信号质量门控 |
| 双PPG与测量会话 | 一路缺失影响整体；新请求可能混入旧窗口；换源沿用聚合 | 一路可用即采集，优先选通过门控的源；新请求清窗；活动会话换源重新稳定 |
| ECG/HRV/呼吸率 | 固定500Hz与实际总线采样速率不符；丢样后继续拼接；HRV窗口过短 | 实测ECG速率、按速率重采样；流中断或速率明显变化清窗；HRV/RSA至少30秒连续窗，SDNN用样本方差 |
| 室早统计 | 用轮询次数代替真实经过时间；第一分钟未形成窗口却显示0 | 用本核真实tick统计，完整60秒窗后才有效，按实际窗长折算次/分钟；断流清窗 |
| 温湿度与共享总线 | SHT转换等待占用通道；选通失败可能读错下游 | 等待转换期间释放锁，读回前重选通道；选通和取锁失败不访问下游；环境只采用SHT，删除板温固定减7℃回退 |
| 双核共享与新鲜度 | 数值/有效标志可能读取不一致；停更仍展示旧结果 | 标量单一发布者、奇偶序号稳定快照；PPG标量/波形关联测量ID；请求带受理序号；本地超时撤有效 |
| 界面、语音、上传、云端 | 有效标志不全或被忽略；旧无效值进入趋势和AI报告 | 消费一致快照；有效标志随值上传；未测显示未测；云端过滤缺标志、非有限值和越界值，旧库补列并保留原始行 |
| BMR/血糖/PAT/血流速度 | 热平衡公式、读取时刻配对或占位值被当作可用测量；血糖缺少合法训练输入 | 当前均保持无效，不进入有效测量展示/评分/报告；保留接口供后续有证据的实现 |

完成PPG结果保留60秒；SHT/MLX/AHT新鲜度3秒，GSR为1秒；M55发现标量序号停更超过3秒撤销对应有效性。ECG消费端100ms无新样本清连续窗口，无分类结果超过3秒也清结果。两核tick起点不同，不能跨核直接相减判断超时。

## 3. 实板验收顺序

以下步骤尚未执行，不能用离线测试通过代替。

1. **成套更新M33和M55并检查启动。** 核对两核正常运行、无手指时不显示心率/血氧、无环境传感器时不编造温湿度。新IPC标记为SDA2/PPG2/ECG2；旧协议不兼容，不能混烧新旧版本。
2. **先证明采样连续。** 记录PPG原始RED/IR、FIFO状态、拒绝原因、源通道和测量ID；记录ECG逐点间隔分布及采样速率。比较空闲、双PPG、温湿度转换、屏幕刷新、WiFi上传及NPU同时工作时的间隔和丢窗率。PPG串口逐点导出会改变负载，导出后的窗口可被拒绝；逐点时间诊断宜先存缓冲再导出。
3. **同步参考对照。** 固定姿势、安静静坐后，以可信心率/血氧参考仪器同步记录；至少覆盖不同人员、不同手指及重复测量。两设备采样窗应对齐，记录参考设备型号、稳定时间、贴合与环境条件，不凭单次读数接近判准确。
4. **测拒绝能力。** 依次检查未放手指、松动、移动、弱灌注/贴合差、ADC饱和、I2C失败、FIFO积压、单路缺失和双路缺失。统计错误被放行比例、有效输出比例和耗时，避免只展示成功样本。
5. **测失效传播。** 新测量请求（含连续按键）必须撤回旧结果；拔线、源停更、ECG断流、两核先后启动及单核重启后，检查界面、语音、上传、数据库、趋势及AI报告都按有效性处理。验证PPG60秒、标量3秒等过期行为和恢复后的重新积窗。
6. **单独验证温度、GSR及模型。** MLX90614当前上报物体/体表红外温度，不当作核心体温；用已知参考目标测试距离、角度和环境影响。SHT与同位置参考温湿度计比较。GSR是相对基线应激分数，不是绝对皮肤电导。ECG分类需用标注数据及实采ECG另验，规则回退必须保留来源标识。

对照数据至少包含：匿名受试者ID、测量ID、时间窗、源通道、算法版本、原始波形、信号质量、结果与有效标志、拒绝原因、参考读数及测量条件。原始记录保留失败样本。训练/标定/验证按受试者分离，不能把同一人的相邻窗口随机分到训练和验证。

建议先采一批基线数据，再冻结工程验收门槛；分别报告心率与血氧的偏差、MAE、误差分布、有效输出率、失败率及测量耗时。对血氧的结果只能说明相对该参考设备的一致性，不能据此声称临床血氧精度。温湿度另按器件量程和参考仪器不确定度制定阈值。

## 4. 后续仍需完成

- **血氧标定：** 修复R值计算不等于完成设备光路标定，经验二次曲线仍需实板参考对照。当前门控范围HR40–150bpm、SpO2 70–100%；超范围报告无法可靠测量，不代表生理上不可能。保留现有SQI阈值等待对照数据，不能凭“数值合理”判断真值或直接放宽。
- **ECG采样：** 平均速率修正不能消除逐点抖动。如果总线满载导致连续窗口频繁失效，应改为有确定时序的采集方案，再验证滤波、重采样、R峰和分类全过程。
- **恢复行为：** 后续批次已加入缺失传感器重试、PPG配置复位检测和重新初始化、活动会话清窗，以及ECG初始化重试；具体范围见设备完善说明。生产任务循环的故障模拟通过，但实板插拔电气恢复尚未验证。
- **HRV/RSA/评分：** 30秒HRV、RSA呼吸率及规则综合评分仍是工程指标；需更长、带参考标注的数据评估，不能包装成临床结论。
- **BMR与血糖：** 先明确年龄、性别、身高、体重、训练单位、输入来源和更新策略，再实现有标志的BMR来源；血糖模型按受试者隔离重新评估及校准，通过后才恢复有效输出。不得用固定BMR或正常血糖占位值填补输入缺失。
- **PAT/血流速度：** 先建立ECG与PPG的真实采样时间同步、传感器间几何/路径与标定契约；读取FIFO的时刻不能当作脉搏到达时刻。

当前可交付结论是“已修复可定位的软件失真与无效数据传播，并通过离线回归和两核构建”。真人和实板精度结论留待上述验收数据。
