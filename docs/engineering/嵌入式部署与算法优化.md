# 嵌入式部署与算法优化

2026-10-28。本轮聚焦M33算法与采集时序、M55故障清理和双核应用包交付。

## 算法与采集

- SQI开方从“以输入值起步、固定12次牛顿迭代”改成标准单精度sqrtf。
  原实现不能保证在18位ADC完整方差量程收敛。独立三角波用已知峰高与方差
  核对PI和幅度变异系数；当前ARM构建生成单精度硬件开方指令。
  未做实板耗时测量，不报告提升百分比。
- 宽平顶只在有上升沿和完整下降沿时记一次峰，使用平台中心位置；窗口末尾
  未下降的平台不计完整峰，避免同一平台被最小峰距切成多次心跳。
- SQI拒绝零/饱和/越界ADC、零/过大采样率；失败时先清输出。门控另外拒绝
  NaN/Inf、负统计量及非法峰数/评分，防旧评分或异常浮点数漏入结果。
- PPG任务检查SQI返回值；FIFO的200ms连续性检查移到获得总线并选通之后，
  使等待互斥锁的时间计入期限，超过期限整窗丢弃。新增边界和tick回绕模拟。

保留原生理范围与经验门限，没有为提高“出数率”放宽门控。上述测试证明软件
处理和边界行为，不证明真人测量精度或血氧标定已经完成。

## GPU初始化失败清理

全量构建暴露SDK的真实错误：裸机分支使用静态Device，但初始化失败路径
调用free(device)；而未到达的堆链表尚未初始化，也会被清理函数遍历。

修复在初始化开始时建立全部空链表；只对动态分配的device执行释放；清理后
将device置空，使重复清理安全。测试直接提取生产SDK的链表实现和初始化/
清理函数，模拟三处显存缺失、三处节点分配失败、重复清理和恢复。

SDK源码被仓库原有忽略规则排除，因此把补丁、原始内容SHA256和回归入口保存在
`tools/firmware/sdk_patch.py`。应用前备份原文件，未知版本拒绝覆盖；统一构建
入口会检查修复。该修改不宣称解决GPU所有生命周期与硬件故障恢复问题。

## 部署入口

见可跟踪说明 `tools/firmware/README.md`。统一命令运行五组固件回归并强制
重编译两核，只归档本次生成的ELF；检查IPC一致、应用段地址/重叠、构建期间
源输入无变化，并提供SHA256与源码/SDK输入指纹。没有绕过测试或单核配包入口。

M33与M55的加载地址映射不同，包中明确记录；只生成应用ELF包，不混入安全
启动/签名镜像，不调用烧录工具。生成目录在`cache/firmware/`，完成标记是
`manifest.json`。更新前运行verify并保留上一个实板验收过的双核包。
